what each reader reads and writes and what it never does; each refusal there is enforced in code
and checked by a test or a source line. Table~\ref{tab:integrations} lists every other connection by
where it runs, with its command and the release that first carried it. None of the readers is endorsed
by or affiliated with the system it reads.
